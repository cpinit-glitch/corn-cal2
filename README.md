## 🧮 สูตรคำนวณกำไร

ค่าคงที่ที่ระบบใช้ (อยู่ในคลาส `CornCalculator`):

| ค่าคงที่ | ค่า |
|---|---|
| น้ำหนักข้าวโพดชื้นต่อคันรถ | 30,000 กก. (30 ตัน) |
| ค่าอบแห้ง | 0.45 ฿ / กก.แห้ง |
| ส่วนลดราคาเม็ดแตก | ถูกกว่าราคาป้าย 2.00 ฿ |
| ส่วนลดราคาฝุ่น | ถูกกว่าราคาป้าย 7.50 ฿ |

ขั้นตอนการคิด:

1. **ความชื้นที่โรงงานใช้** = ความชื้นรับเข้า + ค่า Bias ของโรงงานนั้น
2. เปิด **ตารางหักความชื้นมาตรฐาน** (ช่วง 20–35%) เพื่อหา `%น้ำหนักแห้ง`, `%เม็ดแตก`, `%ฝุ่น` — ค่าระหว่างช่องใช้การประมาณแบบเส้นตรง (Linear Interpolation)
3. **น้ำหนักแห้ง** = 30,000 × %น้ำหนักแห้ง
4. **ต้นทุน** = ค่าซื้อข้าวโพดชื้น + (น้ำหนักแห้ง × 0.45) + (น้ำหนักแห้ง × ค่าขนส่ง)
5. **รายรับ**
   - โรงงานที่ **ร่อน** → แยกเป็นเม็ดดี / เม็ดแตก / ฝุ่น แล้วขายคนละราคา
   - โรงงานที่ **ไม่ร่อน** → ขายน้ำหนักแห้งทั้งก้อนที่ราคาป้ายเต็ม
6. **กำไรสุทธิ** = รายรับ − ต้นทุน แล้วเรียงอันดับทุกโรงงาน

> ตารางหักความชื้นถูก **ฝังไว้ในโค้ด** (`MASTER_MOISTURE_TABLE` ใน `app.py`)
> ไฟล์ `ตารางหักความชื้น.xlsx` ในโฟลเดอร์นี้เป็นเอกสารอ้างอิงเฉยๆ **โปรแกรมไม่ได้อ่านไฟล์นี้**
> ถ้าแก้ตัวเลขในไฟล์ Excel แล้วอยากให้มีผล ต้องไปแก้ `MASTER_MOISTURE_TABLE` ด้วย

## 💾 ระบบเก็บข้อมูล (ข้อมูลไม่หายตอน deploy ใหม่)

ข้อมูลถูกเก็บ **2 ชั้นพร้อมกัน** ทุกครั้งที่กดบันทึก:

| ชั้น | เก็บที่ไหน | รอด deploy ใหม่ไหม |
|---|---|:---:|
| **1. ไฟล์ JSON** | โฟลเดอร์ `DATA_DIR` บนเซิร์ฟเวอร์ | รอด **เฉพาะเมื่อผูก Persistent Disk** |
| **2. Client Storage** | เบราว์เซอร์ในเครื่องคุณแม่เอง | **รอดเสมอ** ✅ |

**ตอนเปิดแอปจะอ่านชั้นที่ 2 ก่อน** → ถ้าไม่มีค่อยอ่านไฟล์ → ถ้าไม่มีอีกจึงใช้ค่าเริ่มต้นในโค้ด
นั่นแปลว่าถึงจะ deploy ใหม่จนไฟล์บนเซิร์ฟเวอร์หายหมด พอคุณแม่เปิดแอปจากเครื่องเดิม สูตรโรงงานที่แก้ไว้จะกลับมาครบและถูกเขียนลงไฟล์ให้ใหม่อัตโนมัติ

### DATA_DIR เลือกที่เก็บยังไง

เรียงตามลำดับ ใครมาก่อนได้ก่อน:

1. ตัวแปรสภาพแวดล้อม **`CORN_DATA_DIR`** (ถ้าอยากกำหนดเอง)
2. **`/var/data`** หรือ **`/data`** ถ้ามีอยู่จริงและเขียนได้ (คือผูก Persistent Disk ไว้แล้ว)
3. โฟลเดอร์เดียวกับ `app.py` (โหมดรันที่บ้าน)

ตอนเปิดโปรแกรมจะพิมพ์บอกว่าใช้ที่ไหนอยู่ เช่น `💾 ที่เก็บข้อมูล: /var/data  (ดิสก์ถาวร)`
ถ้าเพิ่งผูกดิสก์ใหม่ที่ยังว่าง ระบบจะคัดลอกไฟล์ตั้งต้นที่มากับโค้ดขึ้นดิสก์ให้เองครั้งแรก

การเขียนไฟล์เป็นแบบ **atomic** (เขียนไฟล์ `.tmp` ให้เสร็จก่อนแล้วค่อยสลับชื่อทับ) ไฟดับกลางคันไฟล์เดิมจึงไม่พัง

### ⚠️ ถ้าแก้ไฟล์ `factories_config.json` ด้วยมือแล้วค่าไม่เปลี่ยน

เพราะชั้นที่ 2 (เครื่องผู้ใช้) **ชนะไฟล์เสมอ** ค่าที่พิมพ์ใส่ไฟล์เองจึงถูกทับตอนเปิดแอป
วิธีแก้เลือกอย่างใดอย่างหนึ่ง:

- แก้ผ่านหน้า `⚙️ ตั้งค่าโรงงาน` ในแอปแทน (แนะนำ — เขียนลงทั้งสองชั้นให้เอง)
- หรือตั้งตัวแปร **`CORN_DISABLE_CLIENT_STORE=1`** ก่อนเปิดโปรแกรม เพื่อปิดชั้นที่ 2 ชั่วคราวให้ไฟล์ชนะ

> ℹ️ แอปนี้ออกแบบมาสำหรับ **ผู้ใช้คนเดียว** ถ้ามีคนเปิดพร้อมกันหลายเครื่อง สูตรที่แต่ละเครื่องเก็บไว้จะทับกัน

## 🚀 วิธีเปิดใช้งานที่บ้าน

ดับเบิลคลิกไฟล์ **`run_app.bat`** หรือรันคำสั่ง:

```bash
python app.py
```

แล้วเปิด `http://localhost:8550` (เปิดจากมือถือที่ต่อ Wi-Fi เดียวกันได้ ดู IP ที่โปรแกรมพิมพ์ให้)

> ⚠️ **โฟลเดอร์ `.venv` ที่ติดมาใช้ไม่ได้บนเครื่องนี้** — มันถูกสร้างจากคอมอีกเครื่อง (ชี้ไปที่ `C:\Users\ASUS\...`)
> เครื่องนี้ยังไม่มี Python ติดตั้งอยู่ ถ้าจะรัน ต้องติดตั้ง Python 3.12 ก่อน แล้วสร้าง venv ใหม่:
> ```bash
> py -3.12 -m venv .venv && .venv\Scripts\pip install -r requirements.txt
> ```

## ☁️ วิธี deploy ขึ้น Render

1. push โค้ดขึ้น Git แล้วสร้าง Web Service จาก `render.yaml` — ใช้ได้เลยทั้ง **แผน free**
   (ข้อมูลไม่หายเพราะมี Client Storage ชั้นที่ 2 รองรับอยู่)
2. **ถ้าอยากให้ไฟล์บนเซิร์ฟเวอร์อยู่ถาวรด้วย** ต้องอัปเป็นแผน `starter` ขึ้นไป แล้วใน `render.yaml`:
   - เปลี่ยน `plan: free` → `plan: starter`
   - เอาคอมเมนต์บล็อก `disk:` ท้ายไฟล์ออก (mount ที่ `/var/data`)

   แอปจะย้ายไปเก็บไฟล์บนดิสก์ให้เองทันทีโดยไม่ต้องแก้โค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `app.py` | ทั้งแอป — ตารางความชื้น, ชั้นเก็บข้อมูล, เครื่องคำนวณ, และหน้าจอทั้งหมด |
